# ⏳ Liquid Glass Utility Hub

[English](#english) | [Русский](#русский)

---

## English

A simple and beautiful web application featuring a set of everyday tools: Stopwatch, Timer, Password Generator, QR Code Generator, and Calculator. Built with a modern Glassmorphism interface.

This project was created to practice frontend development, focus on interactive UI/UX details, and explore modern web designs.

### 🤖 AI Collaboration
This project was developed by me in collaboration with AI (Claude). I used AI as a coding assistant to learn best practices, optimize UI logic, and implement clean code architecture while keeping full control over the project's vision and features.

---

## Русский

Простое и красивое веб-приложение, включающее в себя набор повседневных инструментов: Секундомер, Таймер, Генератор паролей, Генератор QR-кодов и Калькулятор. Интерфейс выполнен в современном стиле стекломорфизма (Glassmorphism).

Этот проект был создан для практики во фронтенд-разработке, проработки интерактивных UI/UX деталей и изучения современных подходов к веб-дизайну.

### 🤖 Коллаборация с ИИ
Этот проект был разработан мной в сотрудничестве с искусственным интеллектом (Claude). Я использовал ИИ в качестве ассистента по написанию кода, чтобы изучить лучшие практики, оптимизировать логику интерфейса и выстроить чистую архитектуру кода, полностью сохраняя контроль над видением проекта и его функциями.
